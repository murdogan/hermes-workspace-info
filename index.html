Hermes Mail Automation

A private-use assistant integration operated by Murat to manage his own Gmail and Google Calendar through separately configured Asistan and Finans agents.

Purpose and access

With the account holder’s permission, the integration can search and read mail, prepare drafts, send requested messages and attachments, organize mail, read calendar events, and create or change events when authorized. Scheduled actions run according to the account holder’s instructions. Google authorization is required; this website does not sign users in or collect credentials.

This integration is intended for the operator’s personal accounts, not as a public email service. YouTube automation is separate.
